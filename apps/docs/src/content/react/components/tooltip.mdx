## Import

Import the tooltip component.

```tsx
import {
  TooltipProvider,
  Tooltip,
  TooltipLabel
} from "@winnie-ui/react/tooltip";
```

## Anatomy

Arrange the components in the structure below.

```tsx
<TooltipProvider>
  <Button />
  <Tooltip>
    <TooltipLabel />
  </Tooltip>
</TooltipProvider>
```
