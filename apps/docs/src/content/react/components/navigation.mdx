## Import

Import all of the parts of the navigation.

```tsx
import {
  Navigation,
  NavigationItem,
  NavigationItemIcon,
  NavigationItemLabel
  NavigationDisclosure,
  NavigationDisclosureTrigger,
  NavigationDisclosureTriggerLabel,
  NavigationDisclosureTriggerIcon,
  NavigationDisclosureContent,
} from "@winnie-ui/react/navigation";
```

## Anatomy

Arrange the components in the structure below.

```tsx
<Navigation>
  <NavigationDisclosure>
    <NavigationDisclosureTrigger>
      <NavigationDisclosureTriggerLabel />
      <NavigationDisclosureTriggerIcon />
    </NavigationDisclosureTrigger>
    <NavigationDisclosureContent>
      <NavigationItem>
        <NavigationItemIcon />
        <NavigationItemLabel />
      </NavigationItem>
    </NavigationDisclosureContent>
  </NavigationDisclosure>
  <NavigationItem>
    <NavigationItemIcon />
    <NavigationItemLabel />
  </NavigationItem>
</Navigation>
```

## Reference

### NavigationDisclosure

Refer to Base UI [documentation](https://base-ui.com/react/components/collapsible) for more details about the other props and events available on NavigationDisclosure.

### NavigationItem

Refer to React Aria Components [documentation](https://react-spectrum.adobe.com/react-aria/Link.html#props) for more details about the other props and events available on NavigationItem.

| Prop        | Type      | Default     |
| ----------- | --------- | ----------- |
| `isCurrent` | `boolean` | `false`     |

| Selector             | Description                                              |
| -------------------- | -------------------------------------------------------- |
| `data-hovered`       | When the navigation item is hovered with mouse                      |
| `data-pressed`       | When the navigation item is pressed                                 |
| `data-focused`       | When the navigation item is focused with either a keyboard or mouse |
| `data-focus-visible` | When the navigation item is focused with keyboard                   |
| `data-disabled`      | When the navigation item is disabled                                |
| `data-current`       | When the navigation item is the current item in a list              |
