## Import

Import all of the parts of the layout.

```tsx
import {
  Layout,
  LayoutMask,
  LayoutSidebar,
  LayoutSidebarToggle,
  LayoutSidebarResizeHandle
  LayoutContent,
} from "@winnie-ui/react";
```

## Anatomy

Arrange the components in the structure below.

```tsx
<Layout>
  <LayoutMask />
  <LayoutSidebar>
    <LayoutSidebarResizeHandle />
  </LayoutSidebar>
  <LayoutContent>
    <LayoutSidebarToggle />
  </LayoutContent>
</Layout>
```

## State

The `Sidebar` moves between three different states. It uses a breakpoint of 768px to determine when to hide and close the sidebar. Due to a limitation in css, we do not provide an easy way to overwrite this since we cannot use variables in media queries. So, this means that when the sidebar is `docked` it will close when the screen width becomes less than 768px.

### Docked

The `docked` state occurs when the screen width is greater than 768px and the user has decided to have the sidebar open.

Allows the user to interact with the sidebar while it overlays the `LayoutContent`. However, you'll notice that when the breakpoint is hit, the sidebar goes full height, similar to the traditional mobile sidebar menus.
