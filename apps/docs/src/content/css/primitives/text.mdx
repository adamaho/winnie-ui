## Import

Import just the breadcrumbs styles.

```css
@import "@winnie-ui/css/spatial/typography";
@import "@winnie-ui/css/visual/typography";
```

## Anatomy

Attach the appropriate `data` attributes in the structure below.

```html
<span data-component="text" />
```

## Examples
