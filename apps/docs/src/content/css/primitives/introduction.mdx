Winnie CSS provides a css-only set of primitive components based on `data-` attributes. These primitive components are defined on three layers, `spatial`, `visual` and `skin`.

## Example

The primitives provide you with the ability to customize your components to match your brand or style, while we handle details that consume most of your time.
