Winnie CSS provides a css-only set of primitive components based on `data-` attributes. These primitive components are defined on three layers, `spatial`, `visual` and `skin`.

## Spatial

Winnie defines all of the layout, spacing and sizing of a primitive on the spatial layer. Each primitive exports its styles if you wish to import them individually. 

Import all of the primitive spatial styles:

```css
@import "@winnie-ui/css/spatial"; 
```

### Example 

```css
@layer spatial {
  [data-component="button"] {
    padding-inline: var(--wui-button-space, var(--wui-button-md-space));
  }
}
```

## Visual

Winnie offers a visual layer that applies styles to the more popular properties in css. These are things like `background`, `color`, `box-shadow`, etc. It also handles any of the pseudo states like `:hover`, `:active`, etc. Each property is available through a css variable that you can apply in the `skin` layer.

Import all of the primitive visual styles:

```css
@import "@winnie-ui/css/visual"; 
```

### Example 

```css
@layer visual {
  [data-component="button"] {
    &[data-variant="1"] {
      background: var(--wui-button-1-background, var(--wui-button-background));

      &:hover {
        background: var(--wui-button-1-background-hovered, var(--wui-button-background-hovered));
      }
    }
  }
}
```

## Skin

Finally, the `skin` layer allows you to apply styles to a primitive via the css variables defined on the `visual` layer. This typically happens in your application or design system. If you wish to use the predefined skin made by us you are more then welcome to import it from:

```css
@import "winnie-ui/css/skin/winnie";
```

### Example 

```css
@layer skin {
  [data-component="button"] {
    --wui-button-1-background: var(--wui-color-accent-9);
    --wui-button-1-background-hovered: var(--wui-color-accent-10);
  }
}
```
