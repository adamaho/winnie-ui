## Import

Import just the checkbox styles.

```css
@import "@winnie-ui/css/spatial/checkbox";
```

## Anatomy

Attach the appropriate `data-component` attributes in the structure below.

```html
<button data-component="checkbox">
  <i data-slot="indicator"></i>
</button>
```

## Examples

### Size

Use the `data-size` attribute to change the size.

<Demo>
  <div class="row">
    <Checkbox client:load data-size="1" />
    <Checkbox client:load data-size="2" />
    <Checkbox client:load data-size="3" />
  </div>
  <Fragment slot="footer">
    ```tsx ins=data-size="1" ins=data-size="2" ins=data-size="3"
    <button data-component="checkbox" data-size="1">
      <i data-slot="indicator" class="check"></i>
    </button>
    <button data-component="checkbox" data-size="2">
      <i data-slot="indicator" class="check"></i>
    </button>
    <button data-component="checkbox" data-size="3">
      <i data-slot="indicator" class="check"></i>
    </button>
    ```
  </Fragment>
</Demo>

## Reference

Below is a list of the available `data-` attributes available for Checkbox.

| Attribute     | Value                            |
| ------------- | -------------------------------- |
| `data-radius` | `"none" \| "1" \| "2" \| "3"` |
| `data-size`   | `"1" \| "2" \| "3"`           |
