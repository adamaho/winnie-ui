## Import

Import just the button styles.

```css
@import "@winnie-ui/css/spatial/button";
```

## Anatomy

Attach the appropriate `data` attributes in the structure below.

```html
<button data-component="button">
  <i data-slot="icon"></i>
  <span data-slot="label"></span>
  <span data-slot="pending"></span>
</button>
```

## Examples

### Size

Use the `data-size` attribute to change the size.

<Demo>
  <ButtonSizeDemo client:load />
  <Fragment slot="footer">
    ```tsx ins=data-size="sm" ins=data-size="md" ins=data-size="lg"
    <button data-component="button" data-size="sm">
      <span data-slot="label">Edit Dish</span>
    </button>
    <button data-component="button" data-size="md">
      <span data-slot="slot">Edit Dish</span>
    </button>
    <button data-component="button" data-size="lg">
      <span data-slot="slot">Edit Dish</span>
    </button>
    ```
  </Fragment>
</Demo>

### Pending

If a child of the button is rendered with the `pending` attribute, any text and icons rendered in the button will be hidden and the `pending` slot will be rendered.

<Demo>
  <ButtonPendingDemo client:load />
  <Fragment slot="footer">
    ```tsx ins=data-slot="pending"
    <button data-component="button">
      <span data-slot="pending">
        <i class="loader"></i>
      </span>
      <span data-slot="label">New Issue</span>
    </button>
    ```
  </Fragment>
</Demo>

### Full Width

Use the `data-width` attribute to modify the overall width of the button.

<Demo>

## Reference

Below is a list of the available `data-` attributes available for Button.

| Attribute     | Value                                       |
| ------------- | ------------------------------------------- |
| `data-radius` | `"none" \| "sm" \| "md" \| "lg" \| "round"` |
| `data-size`   | `"sm" \| "md" \| "lg"`                      |
| `data-width`  | `"full"`                                    |
